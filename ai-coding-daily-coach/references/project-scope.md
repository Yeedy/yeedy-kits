# Generic Project Scope

Use this only when the current workspace has no recognizable project manifests or source files. Keep questions useful across languages and frameworks.

## Primary Scope

- AI-assisted implementation, debugging, refactoring, and code review
- agent task decomposition, context selection, tool use, and permission boundaries
- test design, acceptance criteria, evaluation, observability, and recovery
- source-grounded research and review of generated changes

## Cross-Cutting Emphasis

- translating an ambiguous request into a bounded change and acceptance criteria
- selecting only the context an agent needs across frontend/backend boundaries
- designing tool permissions and approval points without weakening the sandbox
- verifying generated code with focused tests, static checks, and behavior-level evidence
- evaluating Agent quality, provenance, and failure recovery
- maintaining existing systems safely while using AI Coding tools

## Exclusions

- exact framework APIs, command flags, version numbers, or dependency trivia
- details unique to confidential business data
- generic algorithms disconnected from AI-assisted software development
- questions whose answer depends on memorizing repository-specific filenames
